# Shivank Pandey — Executive Engineering Portfolio

A high-performance engineering portfolio showcasing mission-critical web applications, distributed systems architecture, and enterprise B2B SaaS platforms. Built with a focus on sub-second latency, resilient state management, and high Core Web Vitals fidelity.

## 🚀 Key Production Milestones

- **₹80Cr+ Disbursed Capital**: Architected the multi-journey origination pipeline for Axis Bank / Freecharge, facilitating paperless lending with <0.08% state fallout.
- **-80% Ops Manual Rework**: Engineered automated document verification and pre-flight OCR parsing systems for enterprise sales teams.
- **100+ Enterprise Corporations**: Scaled multi-tenant payroll and expense management systems for large-scale corporate fleets.

## 🛠 Tech Stack

- **Frontend**: React, Next.js, TypeScript, Tailwind CSS, Framer Motion, TanStack Query.
- **Backend**: Node.js, Express, MongoDB, MSSQL, PostgreSQL, Supabase.
- **Systems**: Distributed Systems, RBAC, Microservices, CI/CD, Performance Optimization.

## 📁 Project Highlights

- **NS Travel (Luxury Tours)**: High-end tour orchestration platform for a premier Dubai client.
- **Zelvra Silver Jewelry**: Modern e-commerce storefront with high-DPI macro photography and fluid cart state.
- **ELD Trip Planner**: FMCSA HOS compliance route planner for commercial transport logistics.
- **MedQuvia Health Portal**: Digital health growth platform designed for medical practice appointment conversion.

## ⚙️ Development

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
```bash
npm install
```

### Local Development
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```
